---

## Objectif

Application web dédiée à l'univers de **Pokopia**, pour regrouper toutes les informations concernant le jeu et le gameplay : une encyclopédie.

- Créer notre propre API afin que les utilisateurs puissent utiliser nos données ;
- Système de nos api en  NoSQL avec redis pour les données les plus utilisées ;
- Créer une interface utilisateur originale, tout en étant fluide et érgonomique !

---

## Stack technique

### Back-end
- **NestJS** — Framework Node.js structuré et modulaire
- **PostgreSQL** — Base de données relationnelle
- **TypeORM** — ORM pour la gestion des entités

### Front-end
- **Angular** — Framework TypeScript pour l'interface utilisateur

## Coté Développement

> [!IMPORTANT]
> Récupération du ReadMe original lors de l'installation Angular, donc on le laisse comme mémo ! 

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Code scaffolding

Angular CLI includes powerful code scaffolding tools. To generate a new component, run:

```bash
ng generate component component-name
```

For a complete list of available schematics (such as `components`, `directives`, or `pipes`), run:

```bash
ng generate --help
```

## Building

To build the project run:

```bash
ng build
```

This will compile your project and store the build artifacts in the `dist/` directory. By default, the production build optimizes your application for performance and speed.

## Running unit tests

To execute unit tests with the [Vitest](https://vitest.dev/) test runner, use the following command:

```bash
ng test
```

## Running end-to-end tests
